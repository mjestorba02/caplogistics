1️⃣  INBOUND LOGISTICS
    Purpose: Receive & verify goods from suppliers
    URL: pages/inbound_logistics.php
    Key Fields: shipment_id, supplier, quality, handler
    Status Flow: Pending → Verified → Putaway Complete

2️⃣  STORAGE & INVENTORY
    Purpose: Track inventory with AI forecasting
    URL: pages/storage_inventory.php
    Key Fields: SKU, product, bin_location, current_stock
    Features: Stockout alerts, Movement frequency, Forecasts

3️⃣  OUTBOUND LOGISTICS
    Purpose: Manage order dispatch & tracking
    URL: pages/outbound_logistics.php
    Key Fields: shipment_number, customer, tracking, carrier
    Status Flow: Packed → Loaded → Dispatched → Delivered

4️⃣  RETURNS MANAGEMENT
    Purpose: Handle customer returns & disposal
    URL: pages/returns_management.php
    Key Fields: return_id, reason, classification, inspector
    Status Flow: Initiated → Inspected → Refunded/Disposed

🎯 COMMON WORKFLOWS
═════════════════════════════════════════════════════════════════════════════════

WORKFLOW 1: Supplier Shipment
  1. Create in Inbound Logistics
  2. Mark as "Received"
  3. Check quality
  4. Assign storage location
  5. Add items to Storage Inventory

WORKFLOW 2: Customer Order
  1. Create in Outbound Logistics
  2. Pack items (update status)
  3. Load to carrier
  4. Generate tracking number
  5. Dispatch and track

WORKFLOW 3: Return Processing
  1. Create in Returns Management
  2. Inspect received items
  3. Classify (Resellable/Refurbish/Dispose)
  4. Process accordingly
  5. Mark as Refunded/Disposed
