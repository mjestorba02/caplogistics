📊 API STRUCTURE:
═════════════════════════════════════════════════════════════════════════════════

All 4 APIs follow the same structure:

GET /api/[module].php
  Returns all records in JSON format
  Optional parameter: ?search=query

POST /api/[module].php
  Creates new record
  Body: JSON object with fields

PUT /api/[module].php
  Updates existing record
  Body: JSON with id + fields to update

DELETE /api/[module].php
  Deletes record
  Body: JSON with id

Example Error Response:
  { "status": "error", "message": "Required field missing" }

Example Success Response:
  { "status": "success", "message": "Record saved successfully" }

Scenario 1: New supplier shipment arrives

  3. If resellable: restocked to inventory
  4. If defective: marked for disposal
