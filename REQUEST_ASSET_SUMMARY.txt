────────────────────────────────────────────────────────────────────────────

  2. Look for "Asset Management" in the left sidebar
  3. Click "Request Asset"
  4. Use the 3 tabs:

     • MY REQUESTS: View all your submitted requests
     • TRACK STATUS: See approval progress

USER ENDPOINTS (api/asset_requests.php)
────────────────────────────────────────────────────────────────────────────

  POST /api/asset_requests.php
  ├─ Create new asset request
  ├─ Body: {
  │   priority: "High",
  │   department: "Engineering",
  │   notes: "Optional notes",
  │   items: [
  │     {
  │       asset_description: "Dell Laptop",
  │       quantity: 1,
  │       urgency: "High",
  │       estimated_cost: 1500
  │     }
  │   ]
  │ }
  └─ Returns: {status, request_id}

  GET /api/asset_requests.php?action=my_requests
  ├─ Get user's submitted requests
  └─ Returns: {status, requests: [...]}

  GET /api/asset_requests.php?action=status_summary
  ├─ Get status counts and recent requests
  └─ Returns: {
     status,
     pending_count: 2,
     approved_count: 1,
     in_process_count: 0,
     rejected_count: 0,
     recent_requests: [...]
   }

  DELETE /api/asset_requests.php
  ├─ Delete pending request (owner only)
  ├─ Body: {id: 123}
  └─ Returns: {status, message}

ADMIN ENDPOINTS (api/asset_requests_admin.php)
────────────────────────────────────────────────────────────────────────────

  GET /api/asset_requests_admin.php?action=all&status=Pending%20Approval
  ├─ Get all requests filtered by status
  └─ Returns: {status, requests: [...]}

  GET /api/asset_requests_admin.php?action=details&id=123
  ├─ Get request details with all items
  └─ Returns: {status, request: {...}, items: [...]}

  POST /api/asset_requests_admin.php (APPROVE)
  ├─ Approve pending request
  ├─ Body: {action: "approve", id: 123, notes: "Optional"}
  └─ Returns: {status, message}

  POST /api/asset_requests_admin.php (REJECT)
  ├─ Reject pending request
  ├─ Body: {action: "reject", id: 123, reason: "Required"}
  └─ Returns: {status, message}
