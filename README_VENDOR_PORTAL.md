## 🚀 Quick Start (3 Steps)

### 1️⃣ Import Database
```bash
mysql -u root -p logcap1 < vendor_portal_tables.sql
```
Or use phpMyAdmin to import the SQL file.

### 2️⃣ Access Portal
Navigate to:
```
http://localhost/caplog1/pages/vendor_portal.php
```

### 3️⃣ Start Using!
- Register vendors
- Manage validations
- Track verifications
- Handle requirements
