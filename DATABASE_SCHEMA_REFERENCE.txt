ENUM VALUES:
───────────────────────────────────────────────────────────────────────────────

risk_level:
  - Low      → Low risk supplier
  - Medium   → Medium risk supplier
  - High     → High risk supplier

status:
  - Active   → Currently active
  - Inactive → Temporarily inactive
  - Archived → Archived (no longer used)

API OPERATIONS SUPPORTED:
───────────────────────────────────────────────────────────────────────────────

CREATE (POST):
  INSERT INTO supplier_identification
  (supplier_name, contact_email, certifications, risk_level, phone, notes)
  VALUES (?, ?, ?, ?, ?, ?)

READ (GET):
  SELECT * FROM supplier_identification
  ORDER BY created_at DESC

UPDATE (PUT):
  UPDATE supplier_identification
  SET supplier_name=?, contact_email=?, certifications=?, risk_level=?,
      phone=?, notes=?
  WHERE id=?

DELETE:
  DELETE FROM supplier_identification
  WHERE id=?

CONSTRAINTS:

✓ updated_at is auto-timestamped on UPDATE
✓ Charset: utf8mb4 (supports emojis and special characters)
