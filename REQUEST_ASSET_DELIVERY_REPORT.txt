✅ DATABASE SCHEMA READY

   Tables Created (Pre-existing): 4
   
   asset_requests (Main table)
   ├─ Columns: id, request_id, requester_id, status, priority, total_items
   ├─ Status values: Pending Approval, Approved, Rejected, In Process
   ├─ Auto-tracks: Created by, Created date, Approved by, Rejection reason
   └─ Relationships: One-to-many with items table

   asset_request_items (Detail rows)
   ├─ Columns: id, asset_request_id, asset_description, quantity, urgency
   ├─ Per-item details: Estimated cost, department, notes
   └─ Relationships: Many-to-one with requests table

   asset_request_to_procurement (Bridge table)
   ├─ Purpose: Link requests to procurement module
   ├─ Columns: request_id, procurement_request_id, status
   └─ Future: Auto-created when request approved

   asset_request_audit_log (Audit trail)
   ├─ Tracks: CREATED, APPROVED, REJECTED actions
   ├─ Records: Who did it, When, Before/after values
   └─ Compliance: Complete audit trail for all actions
