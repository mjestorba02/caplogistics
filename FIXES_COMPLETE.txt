✅ ASSET MANAGEMENT & MAINTENANCE - FIXES COMPLETED

=== 1. ASSET MANAGEMENT PAGE - EDIT BUTTON FIX ===
Issue: Clicking "EDIT" button was not opening the modal

Root Cause: 
- Using JSON.stringify() directly in HTML data attribute caused issues with quotes and special characters
- JSON.parse() was failing due to escaped quotes in the attribute

Solution:
- Created window.assetMap object to store asset data in memory
- Changed from data-asset='${JSON.stringify(a)}' to data-asset-id="${a.id}"
- Edit button now looks up asset from assetMap instead of parsing JSON

Result: ✓ Edit button now works correctly
- Click Edit → Modal opens with asset data
- Can update asset fields and save

=== 2. ASSET MAINTENANCE PAGE - ASSET DROPDOWN ===
Issue: Asset ID field was a text input instead of dropdown

Solution:
- Replaced text input with <select> dropdown
- Added loadAssets() function that fetches assets from API
- Dropdown displays: "ITEM_NUMBER - ASSET_NAME"
- Asset Name field auto-populates when selection changes
- Readonly field shows selected asset name

Features:
✓ Dropdown loads all assets from database on page load
✓ Shows both item number and name for easy identification
✓ Asset Name auto-populated and read-only
✓ Clean, user-friendly interface
✓ No manual entry needed
