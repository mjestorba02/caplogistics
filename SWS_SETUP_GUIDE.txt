🔗 API ENDPOINTS REFERENCE:
═════════════════════════════════════════════════════════════════════════════════

All APIs follow the same pattern:

GET Request (Fetch all records):
  Method: GET
  URL: /api/[module_name].php
  Optional: ?search=query
  Response: { "status": "success", "records": [...] }

POST Request (Create new record):
  Method: POST
  Body: JSON object with fields
  Response: { "status": "success", "message": "Record created" }

PUT Request (Update existing record):
  Method: PUT
  Body: JSON with id + all fields to update
  Response: { "status": "success", "message": "Record updated" }

DELETE Request (Delete record):
  Method: DELETE
  Body: { "id": 123 }
  Response: { "status": "success", "message": "Record deleted" }

Example API URLs:
  • /api/inbound_logistics.php
  • /api/storage_inventory.php
  • /api/outbound_logistics.php
  • /api/returns_management.php

📊 WORKFLOW EXAMPLES:
═════════════════════════════════════════════════════════════════════════════════

EXAMPLE 1: INBOUND SHIPMENT WORKFLOW
─────────────────────────────────────
1. Supplier ships goods → Shipment created in Inbound Logistics
2. Goods arrive at dock → Status = "Received"
3. Quality check performed → Status = "Verified", Quality = "Good"
4. Items stored → Storage Location assigned, Status = "Putaway Complete"
5. Items added to Storage Inventory with current stock

EXAMPLE 2: OUTBOUND ORDER WORKFLOW
──────────────────────────────────
1. Customer order created → Shipment created in Outbound Logistics
2. Items picked from inventory → Status = "Packed"
3. Items loaded on carrier → Status = "Loaded"
4. Shipment dispatched → Status = "Dispatched", Tracking # assigned
5. Real-time tracking → GPS location updates
6. Delivered to customer → Status = "Delivered"

EXAMPLE 3: RETURN HANDLING WORKFLOW
───────────────────────────────────
1. Customer initiates return → Return created with reason
2. Goods received back → Status = "Received"
3. Items inspected → Inspector assesses condition, Status = "Inspected"
4. Classification made → Resellable/Refurbish/Dispose
5. Action taken:
   • Resellable → Restocked to inventory
   • Refurbish → Sent to repair facility
   • Dispose → Assigned disposal method

🆘 TROUBLESHOOTING:
═════════════════════════════════════════════════════════════════════════════════

Q: Modules show "No items found" even though I added data?
A: Clear your browser cache (Ctrl+F5) and refresh the page

Q: Error "Unauthorized" when trying to save?
A: Make sure you're logged in and your session is active

Q: Modal doesn't open?
A: Check browser console (F12) for JavaScript errors

Q: API returns 500 error?
A: Check that the database table exists and has correct column names

Q: Search not working?
A: Ensure the search term matches exactly or is a substring
